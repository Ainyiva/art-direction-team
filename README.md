# Art direction team for Domios

A Domios team template I use to find an art direction for a product page: a hero first, then single elements in numbered galleries, then motion for the direction I pick.

## The team

- **Orchestrator.** You talk only to it. It relays each of your notes to the designer word for word and keeps the rounds small.
- **Planner.** Turns the goal into a plan.
- **Designer.** Sends each round as a numbered gallery, so you can say "chip 3, background 2". Each note is one change. It measures references instead of eyeballing them.
- **Animator.** Animates the chosen direction in code and tunes it note by note.

The full process is in [docs/art-direction-playbook.md](docs/art-direction-playbook.md).

## Use it

1. Download `art-direction-team.team`.
2. Double-click it, and Domios opens it for review. Or run `domios team import art-direction-team.team`.
3. Start the team from your templates and send the Orchestrator your references.

You decide every step, and nothing ships without you.
