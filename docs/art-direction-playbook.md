# Art direction playbook

How this team finds an art direction with the owner. Distilled from a real one-day run: 88 numbered variations, two final directions, one chosen and animated.

## Why it works
Edits are cheap when they are small, numbered and relayed exactly. The owner can ask for one more change without paying for it in hours, so they stop settling.

## The loop
1. **References first.** The owner gives references; the team asks what each one is for (the mood, a shape, a palette).
2. **Hero only.** The first round is a few hero variants, to see what direction is even possible.
3. **Go to elements.** When whole heroes make choosing hard, split them into elements and show each set as its own numbered gallery. The owner combines them: "chip 3, background 2".
4. **Iterate.** Each note is one change. The numbers keep growing, and the kept variants are listed.
5. **Narrow to two.** When two directions stand out, show them side by side in the same layout.
6. **The owner picks one.** The others go to history.
7. **Motion.** The animator brings the chosen direction to life; the same loop of small notes applies.
8. **Ship.** When the owner asks, the chosen version goes to the repo by pull request.

## Lessons
- Measure the reference when it is misread. Eyeballing failed twice in the run this comes from.
- Fixed-width artboards hid a layout bug. Check real widths early.
- Review live pages in a real browser, not only in screenshots.
